WEBSITE YAMAHA NMAX — VERSI FOTO ASLI

Cara membuka:
1. Ekstrak website-nmax-v3-foto-asli.zip.
2. Buka folder website-nmax di VS Code.
3. Jalankan index.html di browser atau pakai Live Server.

File HTML, CSS, JavaScript, dan ketiga foto motor harus tetap berada dalam folder yang sama.

Foto yang disediakan: nmax-red.jpeg, nmax-light-blue.jpeg, nmax-blue.jpeg.
Pilihan warna di hero mengganti foto motor berdasarkan foto yang dikirim pengguna. Nama warna hanya label konsep berdasarkan foto, bukan pernyataan warna resmi semua varian.
Tombol Lihat Harga menempel di bagian bawah layar dan menuju halaman produk Yamaha.
